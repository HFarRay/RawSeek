# RawSeek

RawSeek matches camera RAW files to JPG photos by filename. It supports batch search, Finder reveal, and copying matched RAW files to a selected folder.

## Requirements

- macOS 15.0 or later

## Install

1. Open RawSeek.dmg.
2. Drag RawSeek.app to the Applications folder.
3. Open RawSeek from Applications.

## Use

1. Drag JPG/JPEG photos into the import area, or choose them with Choose JPGs. Imported names and thumbnails appear below the drop area.
2. Choose the folder to search for RAW files.
3. Select Search RAW. RawSeek matches files by filename, including files in subfolders.
4. Use Show in Finder to reveal matches, or Copy to Folder to copy them. Copy progress and the current image count are shown while copying.

Supported RAW extensions: RW2, ARW, CR2, CR3, NEF, and DNG.

## Settings and updates

- Use the flags in the title bar to switch between Chinese and English.
- Choose System, Light, or Dark appearance in Settings.
- Settings also include Launch at Login and Show Taskbar Icon.
- Open About RawSeek and choose Check for Updates to import a newer RawSeek DMG.

# RawSeek（中文）

RawSeek 按文件名为 JPG 照片查找对应的相机 RAW 文件，支持批量搜索、在访达中定位，以及将匹配的 RAW 文件复制到指定文件夹。

## 系统要求

- macOS 15.0 或更高版本

## 安装

1. 打开 RawSeek.dmg。
2. 将 RawSeek.app 拖到“应用程序”文件夹。
3. 从“应用程序”中打开 RawSeek。

## 使用方法

1. 将 JPG/JPEG 照片拖入导入区域，或点按“选择 JPG”。导入后会显示照片文件名和缩略图。
2. 选择 RAW 搜索目录。
3. 点按“搜索 RAW”。RawSeek 按文件名匹配，也会搜索所选目录的子文件夹。
4. 使用“在访达中显示”定位匹配文件，或使用“复制到文件夹”复制文件。复制过程中会显示进度和当前图片数量。

支持的 RAW 格式：RW2、ARW、CR2、CR3、NEF、DNG。

## 设置与更新

- 使用页首的国旗按键切换中文和英文。
- 在设置中选择跟随系统、浅色或深色外观。
- 设置中还可配置登录时启动和显示任务栏图标。
- 打开“关于 RawSeek”并选择“检查更新”，可导入新版 RawSeek DMG。

## 版本

1.2
